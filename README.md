# Hermes Agency

The operating system of the Hermes Agency — an autonomous AI product company.

This repo is the company itself: its charter, its doctrine (skills), its memory
(wiki), its templates, and its workforce catalog (vendor agents).

## Mission

Convert verified market problems into real, measurable products — safely,
cheaply, and repeatedly. Never call a prototype a product. Never call a demo
shipped. Never allow an unreviewed claim to become a company decision.

## Structure

```
charter/         Mission, org model, decision rights, principles
skills/          Doctrine skills (how the agency works)
vendor/          Specialist agent workforce catalog
wiki/            Company memory: decision log, ADRs, runbooks, retros
templates/       Handoff/report templates (every artifact schema)
```

## Operating pillars

1. **Discovery 2.0** — 5 modes: problem scan, gap-closing (mid-tier teardown),
   new-tech arbitrage, validated-clone scan, open-source arbitrage.
2. **Scrum, not waterfall** — cross-functional product squads run parallel 2-week
   sprints; departments are capability chapters.
3. **Peer review** — no self-approval; every artifact reviewed independently.
4. **Real > demo** — integrations wired and tested; sandbox is labeled sandbox.
5. **Finance-controlled** — every product has a budget report and forecast;
   no scale spend without proven economics.
6. **Ask, don't guess** — confusion escalates to the board via Telegram.
7. **Public GitHub** — one repo per product; code, evidence, and releases live there.

## Board channel

Telegram. The board approves at gates only: idea pitch, design (for high-risk
items), and release. Everything else the agency runs autonomously.

See `charter/CHANGELOG.md` for the operating-model version history.
